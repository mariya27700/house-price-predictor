# House Price Prediction using Linear Regression

This is a beginner Machine Learning project built using Python, Pandas, NumPy, Matplotlib, and Scikit-Learn.

The project analyzes house data, visualizes patterns using graphs, and predicts house prices using Linear Regression.

---

# Features

- House dataset analysis
- Data visualization using Matplotlib
- Luxury house detection
- Mean, Variance, and Standard Deviation calculation
- Linear Regression model training
- House price prediction
- Model evaluation using ML metrics
